# Support

For usage questions and troubleshooting:

1. Read:
   - `README.md`
   - `docs/cli-reference.md`
   - `samples/demo_work/README.md`
2. If still blocked, open a GitHub issue with:
   - command used
   - error logs
   - relevant input/output paths

For sensitive security reports, use `SECURITY.md` instead of public issues.
