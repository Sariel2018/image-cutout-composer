# demo_work (public-safe sample)

This folder is a minimal, commit-friendly sample job.

- Included:
  - `layout.json` (example row ordering config)
  - `.gitkeep` placeholders for `input/`, `extract/`, `output/`
- Excluded by default:
  - source/reference images
  - extracted crops
  - final rendered outputs

Why:
- keep repository lightweight
- avoid leaking private/commercial character assets

To run locally, place your own files:

1. `input/source.png`
2. optional `input/reference.webp`
3. run scripts from project root
